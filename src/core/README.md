# src/core — infrastructure (no game rules here)

| File | What it is |
| --- | --- |
| `log.ts` | `log` / `warn` / `error`: the only place allowed to use `console` (silent in production builds). |
| `rng.ts` | Seedable random generator (`int`, `float`, `chance`, `pick`, `weighted`, `id`). |
| `events.ts` | Typed event bus (`data:loaded`, `data:error`, `game:ready`, `zone:entered`, `player:moved`, `debug:menu`, `debug:teleport`, `debug:battle`, `battle:ended`, `save:request`, `overlay:closed`, `save:done`, `options:changed`, `debug:delete_save`, `car:ended`, `debug:reloaded`, `story:entered`; see `GameEvents`). |
| `input.ts` | The Input service: `isDown` / `justPressed` / `direction()` for `up/down/left/right/a/b/start/map` (+ `debug` = F2). Keyboard via `bindKeyboard(window)` in `main.ts`; touch (`src/ui/touch-controls.ts`) calls `press/release` with its own source ids, so keys and fingers never release each other. `beginFrame()` runs on Phaser's `prestep`. Text mode (`setTextMode`, `takeTyped`): while on, a key that types one character is queued as text instead of pressing its action (Z / X / WASD / M type letters), Backspace is queued as `'\b'`; arrows, Enter and F2 keep their actions. Used by the Name scene. |

| `debug-flags.ts` | Page-session debug switches: `debugFlags.encounters` (wild encounters on/off), set by the F2 menu and the E2E hooks. |
| `session.ts` | The live game state: `gameState()` (a new game from `start.json` on first use, via `src/logic/new-game.ts`), `setGameState()`, `resetGameState()`. The battle writes the team and bag back here. The Title puts a loaded save here (Continuar) and the Intro the new game; `autosave.ts` keeps the player position in it and saves it. |
| `save-store.ts` | Save store: `SaveStore` over `localStorage` (`saveStore` is the game's). Key `flexymon.save.v1` (`SAVE_KEY`). `load(data)` → `none` / `loaded` (state + migration warnings, logged) / `broken` (bad JSON, schema or empty team: the raw text is copied to `flexymon.save.broken`, `BROKEN_SAVE_KEY`, and the game starts fresh). `write(state)` and `remove()` never throw (full or blocked storage → warning). Format and migration: `src/logic/save.ts`. |
| `story-session.ts` | The story realm's state and slot: `storyState()` (read from `flexymon.story.v1`, `STORY_KEY`, on first use; no slot = a fresh story; an unreadable one is copied to `flexymon.story.broken` and the story starts fresh), `setStoryState()`, `saveStory(quiet?)` (writes, never throws; emits `save:done` `story` unless quiet), `savedStory()`, `removeStory()` and `disableStorySaving()` (debug delete), `useStoryStorage()` (tests). Format and fixes: `src/logic/story.ts`. |
| `autosave.ts` | Auto-save: `Autosave` saves on every `save:request` (`map`, `battle`, `shop`, `healer`, `menu`, `portal`) and emits `save:done`; quietly (no `save:done`) on `pagehide` / page hidden, so a reload at any time comes back to the same tile. Inactive until the first `zone:entered` (the title never overwrites a save); keeps `gameState().player` in step with `player:moved`; `disable()` stops it until reload (debug delete). Wired in `main.ts`. |
| `ui-sound.ts` | Interface sounds: `uiSound(kind)` for `cursor` / `confirm` / `cancel` / `error` / `money` (`sounds.json`); `main.ts` installs the player (`setUiSoundPlayer`: the sound at `sfxVolume()`); every call is kept in a 100-entry history (`uiSoundsPlayed`, hook `uiSounds()`). GridMenu and ChoiceBox play cursor / confirm / cancel / error themselves; scenes add error and money. |
| `audio-unlock.ts` | Audio unlock: `unlockAudioOnFirstInput(target, unlock)` calls `unlock` once on the first `keydown` / `pointerdown` / `touchend` / `mousedown`; `main.ts` then unlocks Phaser's sound manager and resumes the Web Audio context. |
| `options.ts` | Options store: `loadOptions()` reads `flexymon.options` (bad fields → defaults, with a warning), `getOptions()`, `setOptions()` (stores at once, emits `options:changed`), `sfxVolume()` (0–1, pass as `volume` when playing a sound effect). Rules: `src/logic/options.ts`. |
